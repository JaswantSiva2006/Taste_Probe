# Development history

These are TasteProbe's stage-by-stage engineering reports: experiments, live verification logs and completion reports, kept unchanged as evidence of how the product was built. Each describes the system **as it was at that stage**. Several earlier ones describe the original film-to-books product, before the music-only pivot.

For the current system, read [../ARCHITECTURE.md](../ARCHITECTURE.md), [../RECOMMENDATION_ENGINE.md](../RECOMMENDATION_ENGINE.md), [../DEPLOYMENT.md](../DEPLOYMENT.md) and [../LIMITATIONS.md](../LIMITATIONS.md).
